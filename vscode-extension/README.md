# AgentVault: AI Safety Net & Flight Recorder

Native Visual Studio Code and Cursor extension for AgentVault flight recorder and atomic transaction rollbacks.

## Features
- **Real-Time Recovery Timeline:** Live display of all checkpoints generated by AgentVault during AI agent sessions.
- **One-Click Restore:** Safely revert newer agent mutations with a single click.
- **Deduplicated Out-of-Band CAS:** Inspect affected files and mutation triggers.

## Requirements
AgentVault binary installed on system `PATH` (`agentvault`).
